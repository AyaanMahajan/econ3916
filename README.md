# econ3916
My ECON 3916 coursework and projects


Question

How is GDP per capita related to life expectancy across countries in 2007 after accounting for population size and broad region?

Data

I use the Gapminder 2007 country data. Each row represents one country.

Source: https://raw.githubusercontent.com/plotly/datasets/master/gapminderDataFiveYear.csv

How to run

Open ECON3916FINAL.ipynb in Google Colab and run all cells from top to bottom.

Main finding

Countries with higher GDP per capita generally have higher life expectancy. In my main model, doubling GDP per capita is associated with about 3.26 more years of life expectancy, holding population size and region constant and i found this is a conditional association, not a causal effect.
